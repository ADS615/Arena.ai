## 1. Deep Research & 100% Functional Recreation Protocol

1. **Use Search & Analysis Tools First**:
   - Use `web_search` and `fetch_page` (when researching external documentation/specs) and `npm run research -- --target "<Name>" --slug <slug>` to generate a complete **5-Layer Deep Research Spec** (`games/<slug>/RESEARCH_SPEC.json`).

## 2. Ultra-Nice AAA Visual & Audio Polish Standard
Every game and recreated app built in this repository must look and feel like a polished production release:
- **Rich Visuals**:
  - Smooth 60fps rendering with delta-time (`dt`) physics.
  - Dynamic lighting, specular highlights, glowing emissive accents, starfields/backgrounds, and particle burst effects on every action/collision.
  - Sleek dark glassmorphism HUDs (`backdrop-filter: blur(...)`), crisp badges, animated transitions, and screen-shake / juice feedback.
- **3D & Procedural Models**:
  - Import `../../assets/ai-blender-engine.js` or generated `.obj`/`.gltf`/`.js` models so 3D games feature multi-part starfighters, mechs, cars, crystals, and displaced terrain rather than plain boxes.
- **Built-In Synth Audio**:
  - Use the WebAudio API to synthesize responsive sound effects (lasers, boosts, UI clicks, explosions, power-ups, level-ups) with zero external audio file dependencies.
